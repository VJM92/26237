Este proyecto es la puesta en práctica de los conceptos aprendidos en el curso FrontEnd-JS de Talento Tech. 

Consiste en una página web responsiva desarrollada para El Mundo de Mini, una tienda de juguetes de alta resistencia para perros de mordida fuerte.

La página está estructurada con HTML semántico (<header>, <nav>, <main>, <section>, <article>, <footer>) y estilizada con un archivo CSS externo (styles.css). Utiliza Flexbox para la sección de productos, CSS Grid para las reseñas, fuentes de Google Fonts y Media Queries para garantizar un diseño responsivo en móviles. Además, incluye un mapa/video multimedia integrado y un formulario de contacto funcional conectado con Formspree.
